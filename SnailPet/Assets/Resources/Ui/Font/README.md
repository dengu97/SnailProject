# UI 글꼴

여기에 `.ttf` 또는 `.otf` 를 **하나** 떨어뜨리면 UI 글자 전체가 그것으로 바뀝니다.
파일 이름은 상관없습니다. 코드를 고치거나 프리팹을 다시 구울 필요도 없습니다.

비어 있으면 OS 글꼴(맑은 고딕)로 떨어집니다. 어느 PC에나 있어 글자가 네모로
나오지는 않지만, 손그림 UI 와는 결이 맞지 않습니다.

## 고를 때

- **한글 글리프가 있어야 합니다.** 영문 전용 글꼴을 넣으면 한글이 네모가 됩니다.
- **재배포·임베딩이 허용된 라이선스**여야 합니다. 게임 빌드에 글꼴 파일이 그대로
  들어가므로, 「임베딩 불가」 조건이 붙은 것은 쓸 수 없습니다.
- 화면에 8~12px 로 나오므로 **작은 크기에서 읽히는지** 보고 고르세요.
  획이 얇거나 장식이 많으면 뭉갭니다.

## 두 벌 이상 두지 마세요

폴더에서 처음 찾은 것을 씁니다. 여러 벌이 있으면 어느 것이 걸릴지 알 수 없고,
실행 로그에 경고가 남습니다.

## 왜 TMP 가 아닌가

레거시 `Text` 는 TTF 를 그때그때 렌더하므로 한글 아틀라스를 미리 구울 필요가
없습니다. TMP 를 쓰면 글꼴을 바꿀 때마다 2,350자 이상을 다시 구워야 합니다.
