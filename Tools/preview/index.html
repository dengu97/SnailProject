파츠 선택

색상 목록은 PartsColorData 기준입니다. ★ 표시는 해당 파츠의 Colors 컬럼에 실제로 지정된 색입니다.

색상 레이어는 선화 전용입니다. commonshell02_c06 을 commonshell01 선화에 씌우면 실루엣이 달라 색이 윤곽 밖으로 삐져나옵니다. 위 체크박스는 그걸 눈으로 확인하기 위한 실험용입니다.

레이어 순서

뒤 → 앞 순서입니다. 각 파츠는 색상 레이어 위에 선화 레이어가 얹힙니다.

부화 추첨

① EggData 의 PartsGroupIds 에 적힌 모든 그룹의 파츠를 한 풀로 합침 → ② PartsType 별로 AppearWeight 비중 추첨 → ③ 뽑힌 파츠의 Colors 중 1개 선택.

추첨 확률 분포

지정한 알로 대량 추첨을 돌려 파츠별 실제 출현 빈도를 집계합니다. 이론 확률과 비교해 가중치가 의도대로 동작하는지 확인하세요.

알 그룹 선택 시행

파츠 아틀라스

PartsData의 모든 행을 지정된 색상으로 단독 렌더링합니다. 리소스 누락과 색상 매핑 오류가 눈으로 바로 보입니다.

데이터 검증

리소스 존재 여부, ID 충돌, 색상 타입 불일치, 그룹 완결성을 점검합니다.
